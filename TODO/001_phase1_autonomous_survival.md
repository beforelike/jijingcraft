# 001 Phase 1 Autonomous Survival

## 背景

用户要求开发 MC 智能 BOT，项目分两个阶段。第一阶段先实现 BOT 在游戏中自主探索和生存，玩家客户端开放服务器端口为 `8000`。

## 需求检查

- 已确认项目内 Multi Search Engine skill 可用，联网查资料时按该 skill 规则使用。
- 已确认当前仓库原本没有实际源码，只有 Voyager 压缩包和 skill 文件。
- 选择先实现独立 mineflayer 生存 BOT，避免直接改造 Voyager 中偏研究环境的作弊/调试流程。

## 设计结果

- 默认连接 `localhost:8000`。
- 默认离线登录用户名 `SurvivalBot`。
- `MC_VERSION` 默认自动探测；如果服务器自动探测失败，可以显式设置标准 Java 版本号，例如 `26.1.1`。
- 核心采用生存状态机：危险规避、进食、狩猎、采木、制作、采石、熔炉、探索。

## 实现影响

- 新增 Node.js 项目骨架。
- 新增可测试的决策层。
- 新增 README 记录运行方式、当前能力和限制。

## 后续计划

- 增加临时庇护构建逻辑。
- 增加死亡/断线后的重连恢复。
- 接入长期记忆，记录安全点、资源点和失败原因。
- 第二阶段再接入 Voyager/LLM 任务规划与技能库。

## 连接测试记录

- `localhost:8000` 端口可连接。
- 服务器 ping 返回版本 `26.1.1`，protocol `775`。
- 当前 `mineflayer@4.37.0` / `minecraft-protocol@1.66.0` 的支持列表最高到 `1.21.11`。
- 显式 `MC_VERSION=26.1.1` 启动失败：`unsupported protocol version: 26.1.1`。
- 自动探测启动失败：协议层缺少 protocol `775` 的数据。
- 强制 `MC_VERSION=1.21.11` 会被服务器断开：`ECONNRESET`。
- 服务器切换到 `1.21.11` 后，`SurvivalBot` 已能加入服务器并进入 `collect_wood` 决策循环。
- 发现 `protodef` 对 `move_minecart` partial packet 输出刷屏，已接入 `hideErrors` 并默认 `HIDE_PROTOCOL_ERRORS=true` 过滤底层协议噪声。
- 实测 BOT 已能采木、进入基础制作、发现 skeleton 并尝试撤离；夜间压力下死亡后已补充自动 respawn。
- 修复死亡/重生期间旧路径任务继续运行导致位置短暂 `NaN` 的问题：死亡时停止寻路/战斗并暂停控制循环，respawn 后等待位置稳定再继续。
- 服务器切到 `1.21.11` 后最终运行测试通过：BOT 在线列表显示 `SurvivalBot`；从 `-58,63,89` 探索到 `-32,71,142`；随后发现并开始采集 4 个 `spruce_log`。
- 基础制作顺序调整为工作台优先、木棍其次，避免木板不足时先做木棍导致工作台配方失败；采集路径超时现在会降级为 warning 并继续探索。
- 针对“BOT 一直被敌对生物杀死”新增安全模式：威胁半径默认扩大到 20 格，夜间安全半径 28 格；采集/挖矿过程中发现怪物会取消采集并疾跑撤离；Enderman 不再作为普通主动威胁触发撤离，避免误判。
- 新增夜间保守策略：晚上且背包有可用方块时，不再继续开放探索，会尝试用方块搭 2 格高简易围挡并短暂停留，下一轮继续检查天色和威胁。
- 新增无方块时的夜间警戒：默认 `AVOID_NIGHT_EXPLORATION=true`，没有可用围挡方块时也不会主动远探，而是在原地扫描；发现怪靠近时立即疾跑撤离。
- 安全模式验证：BOT 在夜间发现 `creeper` 距离约 27 格时触发 `evade_hostiles` 并执行即时撤离；重启后保持在线，生命值维持满值，没有再次出现连续被怪击杀。
- 修复“白天站在原地”：定位为 `mineflayer-collectblock` 采集任务长时间不返回导致控制循环 `busy=true`。新增 `ACTION_TIMEOUT_MS=25000`，采集/寻路超时后会取消任务、停止移动状态并进入下一轮决策。
- 夜间等待优化：`wait_out_night` 不再只是静等，搭建临时围挡后会复用 `hold_position` 的威胁扫描；如果等待时发现怪靠近，会立即切换到疾跑撤离。
- 修复撤离后持续无效坐标导致再次站桩：撤离时不再持续跳跃；控制循环连续 3 次发现位置无效时会清理移动状态并尝试 respawn 恢复。
- 决策日志新增 `time` 和 `night` 字段，便于区分夜间安全等待与白天动作卡住。
- 采集任务遇到敌对生物时现在会通过 Promise race 立即释放控制循环并撤离，不再等动作超时兜底。
- 修复“BOT 一直没有获取食物”：新增 `FOOD_STOCK_TARGET` 与 `FOOD_SEARCH_RADIUS`，基础工具和武器成型后会在继续开放探索前主动打猎补充食物；打猎过程会追近动物、攻击、收集掉落，并在敌对生物接近时放弃打猎转为撤离。
- 食物来源新增甜浆果采集兜底：附近没有动物时会搜索成熟 `sweet_berry_bush`，靠近后交互采集并收集掉落，适配当前常见的云杉/针叶林环境。
- 修复“BOT 运行一会自己掉线”：入口层改为 session 主循环，`end`/`kicked`/连接前错误会停止当前控制器并按 `AUTO_RECONNECT`、`RECONNECT_MIN_DELAY_MS`、`RECONNECT_MAX_DELAY_MS` 自动重建 BOT；不再断线后静默退出。
- 撤离路径修正：`evade_hostiles` 在疾跑撤离后会重新读取当前位置再计算下一段路径，避免继续使用撤离前旧坐标导致反复靠近怪物。
- 修复“BOT 不熟悉游戏规则、没有建筑和游戏进度”：新增 `progress.js` 第一阶段进度模型，跟踪木器、工作台、镐、石料、熔炉、武器、建筑材料、庇护所、食物储备等里程碑；控制器会输出 `progress`/`progress_stage` 日志。
- 新增建筑目标：`BUILD_SHELTER=true` 时，BOT 在自由探索前会收集建筑材料并搭建一个 3x3 入门庇护所，两层围墙加屋顶；`SHELTER_BLOCK_TARGET` 控制建造前材料目标。
- 实测建造触发后出现 `placed=0`：原因是放块逻辑没有使用地面作为参考面，且草/雪等非完整方块会阻断目标位置。已将向上放置面加入优先级，并在放置前尝试清理可替换目标方块。
- 实测 `placeBlock` 可能在失败位置长时间不返回，导致建造动作卡住；新增 `PLACE_BLOCK_TIMEOUT_MS`，清理目标方块和放置单个建筑方块都会短超时并跳过失败点。
- 进度语义调整为历史累计：已达成的里程碑不会因为后续消耗材料而从 `progress_stage` 中倒退，决策仍会按当前背包继续补资源。
- 增加庇护所进度恢复：控制器启动后会扫描当前位置周围的 3x3 入门庇护所结构，如果检测到足够方块，会恢复 `starter_shelter` 进度。
- 修复“夜间反复被怪杀死导致进度不推进”：夜晚有入门庇护所时不再因为远处怪物撤离，只在 `SHELTER_DEFENSE_RADIUS` 内原地防御；无庇护时只有 `IMMEDIATE_THREAT_RADIUS` 内近距离威胁才撤离，避免被远处怪物诱导离开安全位置。
- 修复饥饿处理过晚：无食物且饥饿低于 `LOW_FOOD` 时直接进入 `hunt_food`，不再等到 `EMERGENCY_FOOD` 才找食物。
- 修复 `craft_basic_tools` 可能空转：工作台定位/放置加短超时；缺少工作台、木板或木棍时会主动补木材，不再连续输出同一决策但不执行有效动作。
- 默认 `PANIC_RETREAT_MS` 从 5500ms 收短到 3500ms，减少夜间逃跑过远、离开安全点并进入新怪物范围的概率。
- 修复“任务规划过早进入探索/下矿”：第一阶段路线改为基地优先，顺序为武器与基础工具 -> 大量食物 -> 房屋材料 -> 5x5 入门房屋 -> 床 -> 农田 -> 动物围栏/诱导动物 -> 持武器寻找或挖掘矿道 -> 煤铁铜等高级材料。
- 默认 `FOOD_STOCK_TARGET` 提高到 18，`HOUSE_BLOCK_TARGET` 提高到 80，新增 `WOOL_TARGET`、`PLANT_CROPS`、`CROP_PLOT_TARGET`、`BUILD_ANIMAL_PEN`、`ANIMAL_PEN_BLOCK_TARGET`、`ADVANCED_MATERIAL_TARGET` 和 `MINE_SEARCH_RADIUS`。
- 新增执行动作：收集羊毛并制作床；采集种子/可种植食物、制作锄头、翻地播种；建造动物围栏并在有饵料时尝试诱导动物；基地完成后优先采集煤/铁/铜，附近无暴露矿物时挖浅层矿道探测。
- 新增测试覆盖基地优先路线：大量食物不足时不探索，建房后先做床和农田，农田后建围栏，基地完成后进入高级材料采集。当前 `npm test` 通过 31/31。
- Live 重启验证时发现房屋恢复扫描可能把天然地形或夜间临时围挡误判为 `starter_shelter`，已改为只在已记录房屋坐标时验证结构，避免跳过真正建房流程。
- Live 夜间验证发现无正式房屋但背包有方块时仍会因远处 skeleton 反复短撤离，已调整为远处威胁继续加固/等待，只有进入 `IMMEDIATE_THREAT_RADIUS` 的近身威胁才撤离。
- 修复“BOT 不会使用工具，砍树仍拿木镐”：新增 `AXES` 工具组，基础工具链会尝试制作斧头；采集前会按目标方块切工具，砍原木优先装备斧头，做不出斧头时会空手砍树并卸下镐/剑/锄等不合适工具。采集日志新增 `tool=...` 便于验证。
- 修复“遇到植物伤害没有避开”：新增伤害方块集合，包括甜浆果灌木、仙人掌、凋零玫瑰、滴水石、岩浆块、火和岩浆；pathfinder 会避开这些方块，决策层会把附近伤害方块作为 `escape_hazard`，健康变化时会取消当前采集并立即逃离。
- 新增测试覆盖伤害植物优先级。当前 `npm test` 通过 32/32。
- Live 验证时发现采集超时后 `collectBlock.cancelTask()` 仍可能阻塞，已为取消采集动作增加 500ms 上限，确保超时后控制循环会恢复。
- 修复“BOT 没有记忆机制，工作台到处都是”：新增 `src/survival/memoryStore.js`，默认将生存记忆保存到 `data/survival-memory.json`；记忆内容包含已知工作台坐标、进度、房屋、农田、动物围栏和矿道探测状态。
- 工作台复用逻辑调整：发现或放置工作台会记录坐标；制作前会优先找附近工作台，再回到记忆中的工作台，最后才考虑放置新的工作台；决策和进度模型会把 `hasCraftingTable` 视为工作台可用，避免工作台放下后因背包为空重复制作。
- 新增配置：`SURVIVAL_MEMORY_ENABLED`、`SURVIVAL_MEMORY_FILE`、`KNOWN_BLOCK_SEARCH_RADIUS`。新增测试覆盖记忆读写和已知工作台复用。当前 `npm test` 通过 36/36。
- 修复“BOT 多次被甜浆果等有害植物杀死”：将甜浆果从普通远离型危险块改为可采集危险植物，成熟甜浆果会先寻找相邻安全格，精确走到安全格后右键采集；危险检测改为接触判定，站在灌木旁边不会误判，真正踩进灌木才触发逃离。
- 受伤逃离优化：健康变化时如果检测到正在接触伤害方块，会先取消采集/移动并短距离疾跑脱离，再尝试寻路到安全位置；捡掉落物时会跳过危险块内的物品，避免为了捡甜浆果再次走进灌木。当前 `npm test` 通过 36/36。
- 检查“BOT 悬浮在空中”：日志显示悬浮前最后一次正常动作是 `evade_hostiles`，随后 `panicRetreatFrom` 手动疾跑后出现 `position is invalid`，后续 `respawn()` 因 BOT 未死亡无法恢复实体坐标，控制循环只能持续等待有效位置。
- 修复悬浮/无效坐标恢复：敌对生物撤离现在优先计算远离敌人的安全落脚点并用 pathfinder 前往；只有找不到安全路径时才短促手动疾跑，且手动前进前会检查下一格是否有安全地面。连续 3 次无效坐标时不再调用无效的 respawn，而是主动断线让自动重连重建实体状态。当前 `npm test` 通过 36/36。
- 检查“BOT 一直重复弯腰，没有做其他有效任务”：日志显示 BOT 在夜晚连续进入 `hold_position`，每轮 `holdPositionSafely()` 都设置 `sneak=true`，8 秒扫描结束后再释放，客户端表现为反复蹲起；同时夜间决策把所有非紧急任务都挡在等待之后，背包里已有材料也不会继续做本地制作。
- 修复夜间无效蹲起：`holdPositionSafely()` 不再默认开启蹲下状态，只保留威胁扫描、撤离和防御；决策层新增夜间安全原地制作优先级，在无近身危险时可制作木板、木棍、基础工具、熔炉或武器，但仍不会夜间主动远探。新增测试覆盖夜间原地制作，当前 `npm test` 通过 38/38。
- Live 验证发现同一夜间策略链路还有远处怪物撤离问题：无正式庇护所、无方块时，25 格外的僵尸仍触发撤离，移动风险高于原地警戒并导致死亡。已改为夜间只有 `IMMEDIATE_THREAT_RADIUS` 内近身怪物触发撤离，远处怪物只保持 `hold_position`。新增回归测试，当前 `npm test` 通过 39/39。
- Live 再验证发现 5.9 格近身僵尸触发撤离后仍有死亡风险：夜间近身威胁如果 BOT 已有武器，现在改为 `defend_self` 原地自卫，生命降到临界值才撤离；没有武器时仍按原逻辑撤离。新增执行动作和测试，当前 `npm test` 通过 40/40。
- 补充修复：`holdPositionSafely()` 内部原本会绕过决策层，对 20 多格外的夜间怪物直接触发 `panicRetreatFrom`。现在内部警戒也遵守同一规则：远处怪物只保持警戒，有方块时加固临时庇护，近身且有武器时自卫，否则才撤离。当前 `npm test` 通过 40/40。
- 针对“BOT 撞上浆果丛后不动、同一件事反复失败”的问题，新增轻量自适应失败学习框架：记忆文件保存 `learning.policyStats` 和 `learning.avoidedPositions`，采集、寻路、甜浆果安全站位和无效坐标恢复会记录失败动作、目标、原因和坐标冷却；后续同类任务会跳过近期失败点，避免重复用同一种方式撞同一处障碍。
- 甜浆果采集进一步改为多安全站位尝试：会按距离排序最多尝试 3 个相邻安全格，每个安全格使用较短寻路超时；连续安全位失败后放弃该浆果丛并回到决策层，避免卡满多个 25 秒长超时。
- 修复“挖了石头却不合成石器”：决策层新增 `craft_stone_tools` 优先级，圆石、工作台和木棍就绪后会从木镐升级石镐，并优先补石剑；执行层的石器制作顺序为石镐、石剑、石斧，避免材料不足时先做石斧而没有武器。
- 新增回归测试覆盖石器升级决策和失败学习记忆，当前 `npm test` 通过 43/43。
- 检查“BOT 被困在坑里面”：日志显示 `collect_stone` 选择了低于当前位置多格的石头目标，`collectBlock` 为追目标下挖后让 BOT 落到 Y=59 附近，随后在坑内反复尝试 `craft_stone_tools` 并出现工作台窗口超时。
- 修复采矿策略：采石和高级矿物采集改为安全侧挖，只选择有相邻安全站位且不会低于当前脚下太多的目标；不再把深处石头直接交给 collectBlock 垂直追挖。找不到安全暴露矿物时，BOT 会挖逐步下降的阶梯矿道，而不是挖竖井。
- 新增坑内逃生动作：控制器会识别周围无同层出口但上方存在坑沿的导航陷阱，优先执行 `escape_pit`；能走到坑沿就直接走，走不到就向墙壁挖上升阶梯，缺支撑时用泥土、圆石、木板或原木垫出梯步。
- 额外修复坑内连锁问题：工作台不可达或窗口未打开时，`craft_item` 不再向控制循环抛出错误并反复刷同一决策，而是记录 warning 和失败学习后返回 false。
- 新增 `miningPlan` 阶梯规划模块和测试，覆盖下降矿道、上升逃生阶梯和方向归一化；当前 `npm test` 通过 47/47。
- 针对“地面也有很多石头，BOT 却直接挖地下石头”的问题，采石目标选择改为地表优先：目标必须是安全侧挖且接近露天的裸露石头，排序上地表石头优先于更近的地下石头；找不到地表石头时先探索寻找山坡/地表石头，连续 3 次失败后才进入阶梯矿道兜底。
