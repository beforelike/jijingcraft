# MC Survival Bot 介绍网页设计文档

**日期**: 2026-05-07
**目标受众**: Minecraft 玩家（双语）
**设计风格**: 沉浸式 Minecraft 像素世界

---

## 设计概述

用户进入一个看起来像 Minecraft 游戏的网页，背景是动态的天空盒（从日出到星空的渐变），地面上有浮动的方块群，中央是 BOT 角色的 3D 像素展示。

---

## 页面结构

### 1. 英雄区（Hero Section）

**背景**:
- Three.js 实现的动态天空盒
- 缓慢移动的云层（像素风格）
- 日夜循环光照效果（暗色主题基调）
- 飘浮的草方块、石头、木头等（缓慢旋转）

**中央展示**:
- 3D 像素 BOT 角色（Steve/Alex 风格的机器人变体）
- BOT 周围环绕着功能图标（镐、剑、面包、工作台等）
- 鼠标移动时，BOT 和方块会轻微跟随（视差效果）

**标题**:
- 双语大标题：「MC Survival Bot」/ 「MC 生存机器人」
- 副标题：用 AI 在 Minecraft 中自主生存
- 按钮：「探索功能」「查看 Demo」「GitHub」

### 2. 功能展示区（Features Grid）

**布局**: 3x2 网格，每个卡片是一个「Minecraft 物品」

**卡片设计**:
- 外观：像游戏里的物品展示框
- 边框：像素风格的木框或石框
- 内容：像素图标 + 标题 + 描述
- 悬停：卡片轻微弹起，边框发光

**六个核心功能**:
1. 🤖 Smart Brain - AI 智能大脑
2. 🛡️ 安全优先 - 本地安全规则
3. 🌳 行为树 - 可执行任务流
4. 📊 Dashboard - 实时监控面板
5. 🧠 记忆系统 - 环境学习与适应
6. 🔬 研究任务 - 可评测任务目录

### 3. 架构可视化区（Architecture）

**设计**: 像 Minecraft 的红石电路图
**展示**: 数据流从 Minecraft Server → BOT → Dashboard 的动画
**交互**: 点击不同节点显示详情

### 4. 快速开始区（Quick Start）

**设计**: 像游戏里的配方书界面
**内容**: 代码安装步骤，带高亮和复制按钮
**语言切换**: 中英切换按钮

### 5. 实时 Demo 预览区

**设计**: 嵌入式的 Dashboard 模拟界面
**展示**: 滚动展示 BOT 状态、决策过程

### 6. 页脚（Footer）

**设计**: 像游戏里的告示牌
**内容**: GitHub 链接、版权、联系信息

---

## 技术实现

### 前端技术栈
- HTML5 + CSS3（自定义属性、动画）
- Three.js（3D 背景、方块动画）
- GSAP（高级动画、滚动触发）
- 纯 CSS 像素艺术（无需图片资源）

### 性能优化
- Three.js 使用低多边形模型
- 移动端回退到静态 CSS 背景
- 懒加载非首屏内容

### 双语支持
- 默认中文，点击切换英文
- 平滑的语言过渡动画

---

## 交互细节

1. **滚动效果**: 页面滚动时天空盒角度变化，功能卡片依次飞入
2. **鼠标交互**: 英雄区跟随鼠标轻微移动（视差），悬停方块时产生粒子效果
3. **点击反馈**: 像素风格的点击动画，按钮按下时像游戏中的按钮
