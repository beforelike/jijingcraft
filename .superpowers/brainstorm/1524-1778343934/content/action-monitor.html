Action Monitoring & Rich Failure Feedback

每个基础动作自带进度监控器，替代超时检测，输出结构化失败原因供 Planner 重规划

核心概念：Action = 执行体 + 监控器 + 失败诊断

Primitive Action 完整定义 (Python @dataclass)
@dataclass
class WalkAction:
    """基础动作：跑"""
    # === 参数 ===
    direction: Direction          # 东/南/西/北
    steps: int                    # 步数
    speed: float = 1.0            # 可选倍速

    # === 监控器（progress_monitor） ===
    def monitor(self, ctx: ActionContext) -> MonitorResult:
        """每 200ms 由 Node.js 侧调用一次，返回进度快照"""
        pos_delta = ctx.current_pos - ctx.start_pos
        elapsed = now() - ctx.start_time
        expected_dist = self.steps * 1.0  # 1 block/step

        return MonitorResult(
            progress=min(pos_delta.length() / expected_dist, 1.0),
            stalled=pos_delta.length() < 0.1 and elapsed > 1.0,
            metrics={
                "distance_traveled": pos_delta.length(),
                "expected_distance": expected_dist,
                "stuck_duration": max(0, elapsed - pos_delta_moving_time)
            }
        )

    # === 失败诊断（diagnose） ===
    def diagnose(self, ctx: ActionContext) -> FailureReport:
        """卡住时自动调用，诊断原因"""
        pos = ctx.current_pos
        block_ahead = ctx.block_at(pos + self.direction.vec)
        block_under = ctx.block_at(pos + Vec3(0, -1, 0))
        nearby_entities = ctx.entities_nearby(radius=2)

        if block_ahead and block_ahead.solid:
            return FailureReport(
                reason="blocked_by_solid_block",
                detail=f"{block_ahead.name} at {block_ahead.pos}",
                suggestion="reroute_or_jump"
            )
        if any(e.type == "hostile" for e in nearby_entities):
            return FailureReport(
                reason="entity_collision",
                detail=f"blocked by {[e.name for e in nearby_entities]}",
                suggestion="evade_or_alternate_route"
            )
        if not block_under or not block_under.solid:
            return FailureReport(
                reason="no_ground",
                detail="walking into air/water gap",
                suggestion="bridge_or_descend"
            )
        return FailureReport(
            reason="unknown_obstruction",
            detail="position unchanged, no obvious block/entity cause",
            suggestion="scan_surroundings"
        )

监控失败 → 结构化反馈 → Planner 重规划

反馈闭环数据流
┌─────────────────────────────────────────────────────────┐
│                   Node.js Action Executor                │
│                                                         │
│  execute(action) {                                      │
│    ctx = ActionContext(start_pos, start_time, ...)       │
│    loop every 200ms:                                    │
│      result = action.monitor(ctx)   ← Python 定义        │
│      if result.stalled:                                 │
│        report = action.diagnose(ctx) ← 诊断卡住原因       │
│        return { status: FAILED, ...report }              │
│      if result.progress >= 1.0:                         │
│        return { status: DONE }                          │
│  }                                                      │
└───────────────────────┬─────────────────────────────────┘
                        │ {status: FAILED,
                        │  reason: "blocked_by_solid_block",
                        │  detail: "stone at (12,64,-3)",
                        │  suggestion: "reroute_or_jump",
                        │  action: "walk",
                        │  params: {direction:"east", steps:10}}
                        ▼
┌─────────────────────────────────────────────────────────┐
│              Task Layer (Python LangGraph)               │
│                                                         │
│  CollectWoodTask.on_action_failed(report):               │
│    if report.suggestion == "reroute_or_jump":            │
│      inject: JumpAction() → retry walk                  │
│    if report.suggestion == "no_ground":                  │
│      task.abort("terrain_unreachable", report)           │
│                                                         │
│  → If task gives up, escale to Planner with:            │
│    { task: "collect_wood",                               │
│      failed_action: "walk",                              │
│      reason: "blocked_by_solid_block",                   │
│      context: {target_pos, block_name, ...} }            │
└───────────────────────┬─────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│            StagePlanner (Python LangGraph)               │
│                                                         │
│  Receives: task=collect_wood,                           │
│            action=walk,                                  │

各基础动作的监控策略

Per-Action Monitor Specs
Action 停滞检测 诊断维度 典型失败原因
walk(dir, steps) 位置 1s 不变 前方方块、脚下方块、近身实体 blocked_by_solid_block, entity_collision, no_ground, in_water
mine(block, tool) 挖掘进度 2s 不增 目标方块变化、工具耐久、距离 block_changed, tool_broken, out_of_range, wrong_tool_tier
collect(item, count) 背包计数 3s 不变 掉落物存在、距离、背包满 no_drops_nearby, inventory_full, items_despawned
attack(entity) 目标血量 1.5s 不减 目标位置、武器伤害、距离 target_out_of_range, target_died, weapon_ineffective, target_fled
place(block, pos) 方块未出现 2s 目标位置、相邻方块、手持物品 position_occupied, no_adjacent_support, wrong_item_in_hand
eat(food) 饱食度 2s 不变 手持物品、饱食度满 food_full, no_food_equipped, food_not_edible
