New Architecture Overview

Python LangGraph Hierarchical Planner + Node.js Action Executor + Priority Preemptive Scheduler

Three-Layer Architecture

Python Smart Brain (LangGraph + LangChain)
Layer 3: Tree Composer
TaskTree = compose(Task₁, Task₂, ..., Taskₙ)
e.g. BuildShelterTree = compose(Explore, CollectMaterials, PlaceBlocks, Craft)
Layer 2: Task Builder
Task = compose(Action₁, Action₂, ..., Actionₙ | condition)
e.g. CollectWoodTask = compose(MoveTo(forest), Scan(LOG), loop: Chop(target) | until count ≥ N)
Layer 1: Primitive Actions (with params)
Action = walk(direction, steps) | jump() | mine(block, tool) | place(block, pos) | eat(food) | attack(entity)
~30 primitive actions, each is a typed Python @dataclass → compiled to JSON → Node.js executes via Mineflayer

Priority Preemptive Scheduler (replaces BehaviorExecutionQueue)

Task Lifecycle with Preemption
Task States:  PENDING → RUNNING → COMPLETED
                  ↓           ↓
              PREEMPTED     FAILED
                  ↓           ↓
              RESUMED     RETRYING (up to N times)
                             ↓
                          GAVE_UP → notifies Planner

Priority Tiers:
  S (900+): Safety   — can preempt A/B/C/D, cannot be preempted
  A (700+): Night/Wait — can preempt B/C/D
  B (550+): Crafting/Tools
  C (400+): Building/Farming
  D (<400): Explore

Preemption rule: new_task.priority > current_task.priority + 100
  → save current_task state → run new_task → restore when done

Anti-blocking:
  - Duplicate detection: by (taskType + constructorArgs hash), not just taskType
  - Stale detection: task in RUNNING > 90s without progress → force fail
  - Slot limit: max 2 per taskType, max 8 total pending
